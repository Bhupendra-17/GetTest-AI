# 🚀 GetTestAI

**GetTestAI** is a full-stack AI-powered mock test platform that allows users to upload PDFs and generate MCQs using an AI model. Users can take tests, track their performance, and view their profile and test history.

---

## Tech Stack

### Frontend:
- React.js
- Tailwind CSS
- Axios

### Backend:
- FastAPI
- MongoDB (via MongoDB Atlas)
- Motor (async MongoDB driver)
- PyPDF2 (PDF extraction)
- Mistral AI 

---


## ⚙️ Features

### 🧠 AI-Based MCQ Generator
- Upload a PDF and extract content.
- Generate questions using an AI model.

### 🧪 Mock Test System
- Display questions with options.
- Track time taken per question.
- View result with scorecard and analytics.

### 👤 User Profile
- Register and login securely.
- View and edit user profile (name, gender, profile pic).
- See test history and performance summary.
